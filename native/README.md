# RowSkan native candidate 0.2

Vehicle inventory by [LIT America](https://litamerica.net).

## Run the app without installing development tools

Open the repository's **Actions** tab and choose a successful **RowSkan release checks** run. Its artifacts include an Android debug APK and complete Windows/Mac preview packages. These are testing distributions, not store-signed production installers. Keep the complete Windows folder together; it includes the SQLite runtime. Real-device camera and upgrade tests remain necessary.

## Included

- On-device SQLite inventory and private application photo files.
- Phone system camera capture, gallery selection, VIN barcode scan and NHTSA lookup.
- Recoverable unfinished intake entries, including photo selections.
- Revision checks preventing stale edits from overwriting newer changes.
- Solo phone-owner management; team phones cannot delete saved records/photos through app operations.
- Recoverable native vehicle deletion and local audit events.
- Password-encrypted .rowskan exports; additive ZIP/legacy import with prevalidation and transactional inventory writes.
- SQLite schema migration from the initial version.

## Boundaries

Internet synchronization, signed device enrollment/revocation, optional cloud storage/billing and store distribution are not enabled. Local permissions do not protect against a device owner tampering with local files. Local databases and photos rely on the device operating system protections; exported backups are separately encrypted.

Browser .rowskan-web backups and native .rowskan backups are separate formats. They are not cross-edition sync. This build limits native backup contents to 200 MB; larger production inventories need streaming exports. Deleted records and drafts are excluded from exports. Removed-photo file retention cleanup remains release work.

## Build from source

Install Flutter stable (CI uses 3.35.7), Python 3 and your platform's native tools. In this directory run:

```
flutter create --org net.litamerica --project-name rowskan --platforms android,ios,windows,macos .
python tool/configure.py
flutter pub get
flutter analyze --no-fatal-infos --no-fatal-warnings
flutter test test/store_test.dart test/database_test.dart test/hardening_test.dart
```

Then use `flutter build windows --release`, `flutter build macos --release`, or `flutter build apk --debug`. Windows requires Visual Studio with Desktop development with C++; Mac/iOS requires Xcode, CocoaPods and Apple signing configuration for real-device releases. iOS minimum target is 15.5. Standard runners are generated by Flutter; do not commit credentials, certificates or real inventory.
