# RowSkan demo 2

Vehicle inventory by [LIT America](https://litamerica.net).

- `docs/`: browser demo; configure GitHub Pages to deploy from main /docs.
- `native/`: native local-first app source for Android, iOS, Windows and macOS.
- GitHub Actions builds Android, Windows and Mac previews. Native apps are development previews, not production releases.

The browser demo stores inventory locally in each browser. Automatic device sync, cloud subscriptions and camera VIN text recognition are not implemented.
